## 2. 当前版本功能清单（正式版 v1.0.0）

### 核心刷题
- 刷题/复习/错题重刷三模式；FSRS 四档评分（Again/Hard/Good/Easy）
- 五题型：单选 / 多选 / 判断 / 填空 / 简答（含等价答案分组判分）
- 今日任务卡、随机刷（50/100/150）、章节/重点合集、模拟考试、错题本（连续答对自动移出）
- **答题卡**（本轮新增）：按题型分区、红绿灰三态（对/错/未答，部分对归入错）、点格子二次确认跳题、完成页整轮回顾、**中途退出再进入自动恢复进度**

### 题库治理与管理（本轮新增）
- 题库包管理（设置 → 数据与题库）：每库菜单 = 编辑题目 / 清理归档 / 隐藏（保数据）或恢复 / 彻底删除（输入库名确认，不可恢复）
- 题目浏览器 + 编辑表单：章节/题型/关键词搜索、审题标记联动、编辑题干/选项/答案/解析/章节/等价答案
- **用户修改保护**：编辑过的题打 `user_edited` 标记，内置题库更新导入时跳过覆盖（保留本地版）；编辑页可"还原为官方版"
- **内置题库自动更新**：启动时按 manifest 版本比对（轻量读版本，不一致才全量导入），解决"手动导入过就不更新"问题
- 审题标记**常驻**（正式版不再隐藏）：刷题页旗子 + 设置页导出 JSON

### 外观与体验
- 主题面板：主色/背景图/透明度/圆角/深色模式 + **隐藏状态栏开关**（沉浸全屏）
- 全局背景（本地图片 + 渐变遮罩）、刷题计时器、练习进度续刷
