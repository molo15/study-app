## 三、问题项（按优先级排序）

### 🔴 P1 - 功能缺陷

#### P1-1：首页"考试倒计时+每日目标卡"点击进入占位页

- **文件**：`app/lib/ui/pages/v3/home_v3_page.dart`
- **位置**：第 497 行 `onTap: () => _push(const SettingsPagePlaceholder())`
- **现象**：用户点击首页考试倒计时卡（显示"距离考试 106 天"），进入一个显示"阶段3 接入"的空白占位页
- **根因**：`SettingsPagePlaceholder` 是阶段三前的临时占位类（第 577-591 行），设置页 V3 已实现为 `SettingsV3Page`，但首页卡片的 onTap 未更新
- **修复建议**：将 `_push(const SettingsPagePlaceholder())` 改为 `_push(const SettingsV3Page())`，或直接切换到底部 tab 的"我的"页；修复后删除 `SettingsPagePlaceholder` 类（死代码）

### 🟡 P2 - 设计不一致

#### P2-1：AppSidebar（桌面端侧边栏）仍是 V2 冷磨砂风格，未 V3 令牌化

- **文件**：`app/lib/ui/widgets/app_sidebar.dart`
- **现象**：桌面端（≥1200px）用户看到的左侧边栏是 V2 冷磨砂风格（硬编码色 #4F7CD4 / #56647C / #8B98AE 等），与 V3 内容页（IOSColors 令牌）混搭
- **证据**：app_sidebar.dart 中至少 10 处 `Color(0x...)` 硬编码，无 `IOSColors` / `IOSSpacing` / `IOSRadius` 引用
- **影响范围**：仅桌面端（≥1200），iPad 和手机不受影响（用底部 FloatingTabBar）
- **修复建议**：新建 `ios_sidebar.dart` 组件，用 V3 令牌重写（液态玻璃背景 + IOSColors + IOSSpacing + 66px 图标栏 / 232px 全宽），替换 root_page 中的 AppSidebar 引用；旧 AppSidebar 保留不删除

#### P2-2：ios_install_guide.dart 未 V3 令牌化

- **文件**：`app/lib/ui/widgets/ios_install_guide.dart`
- **现象**：7 处硬编码色值（#4F7CD4 / #56647C），未用 IOSColors 令牌
- **影响范围**：iOS 安装引导页（首次安装或 PWA 引导时显示）
- **修复建议**：将硬编码色替换为 `IOSColors.of(context).primary` / `IOSColors.of(context).text2`

### 🟢 P3 - 优化与待验证

#### P3-1：SettingsPagePlaceholder 死代码未清理

- **文件**：`home_v3_page.dart` 第 577-591 行
