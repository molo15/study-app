## 一、设计定稿（已确认，不再变更）

### 1.1 设计语言：冷磨砂（Cold Frosted Glass）

三支柱——**流动 / 沉浸 / 质感**：

| 支柱 | 落点 |
|---|---|
| **流动** | 页面切换淡入上移+级联浮现、二级页左滑 push、进度条/柱状图生长动画、卡片按压缩放 |
| **沉浸** | 背景光斑固定最底层，所有页面共享、切换永不跳动；毛玻璃贯穿；内容区首卡紧贴顶栏下方（间隙 6px） |
| **质感** | 多层毛玻璃（blur 24/16/12px 三档）、1px 半透明白边、顶部高光描边、柔和渐变数据可视化 |

色彩（冷色系）：
- 背景：冷灰蓝渐变 `#e7eef7 → #c9d7ea` + 4 个漂浮光斑（冷蓝）
- 玻璃卡：`rgba(255,255,255,.74→.40)` 渐变 + `backdrop blur 24px saturate 170%`
- 强调色：冷青蓝 `#4f7cd4`（主）/ `#7aa2ee`（亮）
- 语义色：正确 `#3fa88a` / 警告 `#e0a13c` / 错误 `#d4646a`
- 文字：主 `#1e2a3c` / 次 `#56647c` / 弱 `#8b98ae`
- 圆角：26 / 18 / 13 三档

### 1.2 页面全貌（9 界面）

底部导航 5 Tab：**今日 / 题库 / [背题·中央圆钮] / 统计 / 我的（替代设置）**

| 界面 | 要点 |
|---|---|
| 今日（信息流） | 顶栏问候+倒计时 · Hero 今日学习(环形进度) · 今日队列(到期复习/可新学) · 快捷三卡(模拟卷/错题本/背题卡) · 五科入口 · 学习数据 |
| 题库 | 搜索框 · 综合模拟卷 Banner · 五科列表(进度条+掌握度) |
| 背题总览 | 不背单词式说明卡 · 各科知识点环形进度 · 点击进卡 |
| 背题卡 | 3D 翻转（正面知识点名 → 背面要点）· 顶部进度段 · 底部"还不会/背会了" |
| 统计 | 总掌握度大环 · 各科掌握度条形(生长动画) · 近7日柱状图 · 四格数据 |
| 我的（设置） | 个人卡(目标院校/数据) · 学习(考试倒计时/每日提醒开关) · 题库(题库包管理/主题定制) · 通用(导出/导入/关于) |
| 答题（二级） | 题干紧贴顶栏 · 选项玻璃卡 · 提交揭示解析+知识点标签 · 切题归位 |
| 答题卡（二级） | 题号网格四态(当前/已答/答错/未答/标记虚线) · 点击跳题 |
| 模拟考（二级） | 顶栏计时器+进度 · 标记/上一题/下一题/交卷 · 交卷→成绩页 |
| 结果页（二级） | 分数大环 · 各科得分条形 · 逐题复盘/只看错题/再来一套 |

### 1.3 标记语义（定稿：不混用）

| 标记 | 场景 | 图标 | 语义 | 答题卡呈现 |
|---|---|---|---|---|
| **存疑标记** | 模拟考 | ◆ 菱形 | 这题不确定，交卷前回看 | 虚线框"待回看" |
| **审题标记** | 练习 | 🚩 旗子 | 题目有误/待修改，反馈给作者 | 已答内区分，默认关 |

两者独立开关、独立语义，不混用。收藏职能由错题本承担。

## 二、Flutter 技术方案

### 2.1 主题系统改造（`theme_controller.dart`）

- `AppThemeConfig` 增加冷磨砂字段：`bgTop/bgBottom`（渐变端点）、`blobColor/opacity`（光斑）、`glassOpacity`（玻璃强度）、`accentColor` 切换
- 新增主题预设"冷磨砂"（默认）；保留现有主题兼容
- `ThemeController` 加载时默认使用冷磨砂，旧主题配置做迁移兜底

### 2.2 组件库（新增 `lib/ui/widgets/`）

| 组件 | 说明 |
|---|---|
| `FrostBackground` | 全局背景：渐变 + 光斑（`Stack` + 模糊圆），放在 `RootPage` 最底层，页面共享 |
| `GlassCard` | 毛玻璃卡片：`BackdropFilter` + 半透明白渐变 + 白边 + 顶部高光 + 阴影 |
| `GlassAppBar` | 渐隐毛玻璃顶栏（内容滚过透出） |
| `GlassTabBar` | 毛玻璃底栏 + 中央圆形"背题"凸起按钮 |
| `ProgressSeg` | 分段进度条（答题/背题页顶栏内） |
| `CircularRing` | 环形进度（Hero / 统计 / 背题总览） |
| `FlippableCard` | 3D 翻转卡（背题卡） |
| `StaggeredFade` | 级联浮现动画容器 |

### 2.3 导航改造（`root_page.dart`）

- Tab 从 3 扩到 5：今日/题库/背题/统计/我的
- 自绘毛玻璃底栏替代 Material `NavigationBar`，中央圆形凸起背题按钮
- 保留 `IndexedStack` 常驻 + 切换上滑过渡；**背景光斑在最底层，切换不露背景**（解决"背景浮现其他页面"）

### 2.4 页面重构清单

| 页面 | 改动 |
|---|---|
| `home_page.dart` | 全量重构为今日信息流（Hero/队列/快捷/五科/数据） |
| `bank_page.dart` | 保留五科数据，改玻璃卡列表 + 模拟卷 Banner + 搜索框 |
| `stats_page.dart` | 总环 + 各科条形(动画) + 7日柱状 + 四格 |
| `settings_page.dart` | 改造成"我的"页（个人卡+分组列表） |
| `practice_question_view.dart` | 题干卡玻璃化、选项玻璃卡、解析揭示、底部固定按钮、切题归位 |
| `knowledge_memorize_page.dart` | 背题卡 3D 翻转、顶栏进度段 |
| `mock_exam_page.dart` | 顶栏计时器、存疑标记、底部固定栏 |
| 新增答题卡/结果页/背题总览 | 按原型实现 |

### 2.5 动效实现

- 页面切换：保留 `_SmoothTabView` 上滑，加透明度 + 级联
- 二级页：`PageRouteBuilder` 左滑 push（`SlideTransition`）
- 背题卡翻转：`AnimatedBuilder` + `Transform`（`Matrix4.rotationY`）+ `perspective`
- 进度/条形：`TweenAnimationBuilder`
- 统一 `reduceMotion` 开关（已有）

### 2.6 数据层

- 首页信息流数据聚合：`HomeProvider` 从 repository 聚合今日队列（FSRS 到期 + 可新学章节数）
- 存疑标记：模拟考答题状态新增 `flagged` 字段（沿用审题标记 DB 结构或独立字段，落地时定）
- 均向后兼容现有 DB（v9 增量迁移）

## 四、风险与决策点

| 风险/决策 | 说明 |
|---|---|
| 毛玻璃性能 | `BackdropFilter` 在低端机有开销，光斑/玻璃数量控制；`reduceMotion` 兜底 |
| 主题迁移 | 旧用户已有主题配置，需迁移兜底为冷磨砂 |
| 5 Tab 导航 | 原 3 Tab 页面（错题本/模拟卷入口）需重新挂接，避免入口丢失 |
| 存疑标记 vs 审题标记 | 数据字段分离，各自独立开关（已定稿） |
| 信息流数据 | 今日队列的"到期复习"依赖 FSRS，需确认 repository 已有到期查询能力（无则补） |
