### 1. [修辞] 夸张
- id: `bank-xiandai-hanyu:z_gen_xy2_001244`
- 知识点: None · tags: AI扩充简答, 修辞
- 答案: 夸张是故意言过其实、夸大或缩小事物的特征。
    1. 扩大夸张：往大处说，如“白发三千丈”。
    2. 缩小夸张：往小处说，如“一眨眼工夫”。
    3. 超前夸张：把后出现的事说成先出现，如“还没喝，就闻到酒香了”。
    注意：夸张要以真实为基础，合乎情理，不能违背事实逻辑。

### 2. [修辞] 排比
- id: `bank-xiandai-hanyu:z_gen_xy2_001246`
- 知识点: None · tags: AI扩充简答, 修辞
- 答案: 排比是把三个或三个以上结构相同或相似、意义相关、语气一致的短语或句子排列起来。
    1. 定义：三项或三项以上的成排排列。
    2. 效果：增强语势，突出强调，增强节奏感和感染力。
    3. 例：“时间就是生命，时间就是速度，时间就是力量。”
    排比与对偶不同，对偶限两项，排比一般三项以上。

### 5. [修辞] 借代
- id: `bank-xiandai-hanyu:z_gen_xy2_001242`
- 知识点: None · tags: AI扩充简答, 修辞
- 答案: 借代是不直接说出要说的人或事物，而借用与其相关的事物来代替。
    1. 特征代本体：如“红领巾”代少先队员。
    2. 部分代整体：如“不拿群众一针一线”。
    3. 具体代抽象：如“我们的时代需要千千万万个雷锋”。
    4. 专名代泛称、工具代本体等。
    借代重在“相关”，借喻重在“相似”，二者不同。

- 答案: 对偶和对比是两种不同的辞格：
    1. 对偶：结构相同、字数相等、意义相关的两个短语或句子成对排列，如“两个黄鹂鸣翠柳，一行白鹭上青天”。
    2. 对比：把两种对立的事物或同一事物的两个方面并举比较，如“虚心使人进步，骄傲使人落后”。
    3. 区别：对偶重结构形式，对比重内容关系；对偶不一定对比，对比不一定对偶。

### 9. [修辞] 比喻

- 知识点: None · tags: AI扩充简答, 修辞
- 答案: 比喻是用他物来打比方说明本体的辞格。
    1. 明喻：本体、喻体、喻词都出现，如“像、好像”，例“他像牛一样壮”。

    3. 借喻：不出现本体和喻词，直接用喻体代本体，如“看，一群大雁往南飞”（代指迁徙的人）。
    4. 注意：喻体要常见易懂，本体和喻体要有相似点，感情色彩要一致。

### 18. [文字] 异体字与异读词
- id: `bank-xiandai-hanyu:z_gen_xl_001218`
- 知识点: None · tags: AI扩充简答, 文字
- 答案: 异体字是音义完全相同而形体不同的字。
    1. 定义：异体字在任何语境下都可互换而不影响意义，如“泪—涙”“峰—峯”。
    2. 整理原因：异体字造成用字混乱，增加学习和使用负担。
    3. 整理原则：保留规范字，淘汰异体字，如“泪”规范、“涙”淘汰。
    4. 整理异体字是汉字规范化的重要内容。
- 缺失: explanation（解析）

### 19. [文字] 形声字
- id: `bank-xiandai-hanyu:z_gen_xl_001215`
- 知识点: None · tags: AI扩充简答, 文字
- 答案: 形声字由形旁和声旁构成：
    1. 形旁作用：表示字的意义类属，如“氵”提示与水有关。
    2. 声旁作用：表示字的大致读音，如“湖”的“胡”。
    3. 局限：形旁只表示类属，不能精确表义；声旁表音不准确，古今音变导致“秀才识字读半边”常出错。
    4. 意义：形声字占汉字绝大多数，是能产的造字方式。

### 20. [文字] 汉字的形体演变
- id: `bank-xiandai-hanyu:z_gen_xl_001211`
- 知识点: None · tags: AI扩充简答, 文字
- 答案: 汉字形体的演变大致经历：
    1. 甲骨文（殷商）：刻于龟甲兽骨，象形程度高。
    2. 金文（商周）：铸于青铜器。
    3. 篆书：包括大篆和小篆，小篆是秦统一后的规范字体。
    4. 隶书：由小篆演变而来，是古今汉字的分水岭。
    5. 楷书：现行通用字体，又称真书、正书。
    演变总趋势是由繁到简，由象形到符号化。
- 缺失: explanation（解析）

### 21. [文字] 六书
- id: `bank-xiandai-hanyu:z_gen_xl_001214`
- 知识点: None · tags: AI扩充简答, 文字
- 答案: “六书”是古代分析汉字构造的六种方法：象形、指事、会意、形声、转注、假借。
    1. 象形：描摹事物形状，如“日、山”，多为独体字。
    2. 指事：用象征符号或在象形字上加标记，如“上、下、本、末”。
    3. 会意：两个以上偏旁组合表新义，如“休、武”，是合体字。
    4. 形声：形旁表义、声旁表音，如“江、河”，最能产。
    转注、假借是用字法。
- 缺失: explanation（解析）

### 22. [文字] 独体字与合体字
- id: `bank-xiandai-hanyu:z_gen_xl_001213`
- 知识点: None · tags: AI扩充简答, 文字
- 答案: 独体字与合体字是从字形结构划分的：
    1. 独体字：不能再拆分为两个或两个以上部件的字，如“日、月、人、手”。
    2. 合体字：由两个或两个以上部件组合成的字，如“休、江、明”。
    3. 象形、指事多为独体字，会意、形声多为合体字。
    4. 划分独体、合体有助于理解汉字结构。

### 24. [文字] 偏旁与部首
- id: `bank-xiandai-hanyu:z_gen_xl_001216`

    4. 有的字没有部首（独体字以其本身为部首）。

### 27. [标点符号] 句内点号
- id: `bank-xiandai-hanyu:z_gen_xy2_001254`

- 答案: 句内点号表示句内停顿，各有分工：
