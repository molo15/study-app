> 方法：逐一比对两份题的 `stem / options / answer / explanation`，判断是「选项重排（实质都对）」还是「答案真冲突」，并给出更规范的一份。
> 结论先行：**3 组均无"错题"，组 3、组 6 是选项顺序不同造成的字母差异（内容都正确），组 5 是单选 vs 多选的形态差异（多选版更规范）。**

## 组 3 ·「见」的用法（单选，两版答案 B vs A）

| 项目 | q_000046 | b_000360 |
|---|---|---|
| 章节 | 基础-语法（上） | 基础-语法（上） |
| 选项 A | 助动词，表被动 | 指代性副词，指代第一人称「我」 |
| 选项 B | 指代性副词，指代第一人称「我」 | 表被动的助动词 |
| 选项 C | 介词，引进主动者 | 动词看见 |
| 选项 D | 动词，义为「看见」 | 介词引进主动者 |
| **答案** | **B** | **A** |
| 解析 | 本为助动词的「见」，魏晋以后产生称代用法，变为指代性副词，指代第一人称，「慈父见背」即「慈父背我」，意为父亲去世。 | 「见」本为助动词，魏晋后有了称代用法，变为指代性副词指代第一人称；「慈父见背」即「慈父背我」（父亲去世）。 |

**判定：两份解析文字一致，正确内容都是"指代性副词，指代第一人称"。差异纯粹是选项 A / B 互换了位置（B 版把"表被动"放 A，"指代"放 B；A 版反过来），所以字母不同但实质等价、都正确。**

> 建议：**任选一份保留即可，删掉另一份**。推荐保留 `q_000046`（带"（拓展）"标记，解析更完整）；删除后注意选项布局——把"指代性副词"固定在 A 位更符合多数题库惯例（"表被动"作为干扰项即可）。

## 组 5 · 古汉语中的否定副词主要有（单选 vs 多选，形式多样）

| 项目 | b_000357（单选） | q_000053（多选） |
|---|---|---|
| 章节 | 基础-语法（上） | 基础-语法（上） |
| 选项 | A 不弗毋勿未否非无莫 / B 皆悉咸尽 / C 甚极殊颇 / D 既已尝曾 | A 不弗 / B 毋勿 / C 未莫 / D 皆悉 / E 甚极 |
| **答案** | **A** | **A / B / C** |
| 解析 | 否定副词主要有不、弗、毋、勿、未、否、非（匪）、无、莫等；B 为范围副词，C 为程度副词，D 为时间副词。 | 解析：否定副词主要有「不、弗、毋、勿、未、否、非（匪）、无、莫」等；「皆、悉」表范围，「甚、极」表程度，均非否定副词。（变式） |

**判定：这是真正的"形态差异"——一份做成单选题（把整个否定副词集合作为一个选项 A），一份做成多选题（拆成 A 不弗 / B 毋勿 / C 未莫，并单独列出 D 范围副词、E 程度副词作干扰项）。两份解析都说否定副词含"不弗毋勿未否非无莫"，且都明确排除了范围副词、程度副词，知识点都对。**

> 建议：**以多选版 `q_000053` 为基准更规范**。理由：①"下列词语中属于否定副词的有"本就是考研典型多选题，多选才能完整考察"识别 + 排除干扰"的能力；② 多选版的干扰项（范围/程度副词）逐一列出，区分度更清晰。
> 处理方式二选一：
> - 直接删除单选版 `b_000357`，保留 `q_000053`；
> - 或保留单选但把它改成多选（把 b_000357 的 A 拆开）。若保留单选版，建议补上"否、非、无"——它比多选版列得更全。
> **推荐：删 b_000357、留 q_000053。**
