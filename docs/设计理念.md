> 建立日期：2026-08-31

>

## 0. 一句话定位

> **以知识点为骨架、按"记忆—应用"分层喂题、质量红线高于数量、把控制权交给用户的考研刷题系统。**

---

## 1. 产品层核心

**"知识点的记忆与迁移"是唯一主线，题目只是载体。**

- 用户的真实需求不是"刷完多少题"，而是"背完能记得住、考场上用得出"。
- 因此一切功能的验收标准是：**它是否服务于知识点被记住、被用出。**
  - 服务于"记住"：基础题（直问直答）、背题模式、知识点卡、章节概览
  - 服务于"用出"：测试题（综合应用）、模拟卷（随机综合）
- 不与这两件事直接相关的功能（如无谓的统计、形式完整的考试）都让位于主线。

## 2. 七环节设计核心

### 2.1 内容层 · 出题
> **核心：知识点直问直答 + 同域等长干扰项，覆盖到"背完记得住"为止。**

- 每章先有知识点清单，每个知识点出直问直答基础题
- 干扰项同域等长，杜绝"都选 A"这类结构性提示
- 变式重复直接删——出题目的是覆盖记忆点，不是堆量
- 判分按要点组积分，给部分分（partial）

### 2.2 结构层 · 知识点框架
> **核心：先有目录，后有题；框架是骨架，题目是填充物。**

- 按素材目录先确定答题结构，再回头看题库缺口（"标点符号章"教训）
- 章节知识概览页 + 知识点树 + questionCount
- 思源笔记做骨架，App 内知识点卡从基础题自动派生
- **跨科知识点重叠为设计内保留**（如现汉/古汉同考六书、现当代同考梁实秋）：各科独立刷题互不干扰，
  体现知识点在学科间的交叉；如需进一步去重按「科目优先级」策略处理，不默认删题

### 2.3 记忆层 · 背题模式
> **核心：只推不考，直到背会；不打扰正常复习队列；进度可存档、可重置。**

- 不背单词式推送（不会的卡每隔 5 张推回），不进 FSRS/错题本
- 背题卡从基础题自动派生；知识点卡 = 知识点名称 + 提炼要点 summary
- **背题存档（v11）**：跨会话持久化，自评即时落库；已掌握的不再进队列，
  未掌握的进入时优先推送；全部掌握后提供「重新开始」（重置存档）——存档只记"掌握/未掌握"，
  不建立 FSRS 调度，不占复习队列

### 2.4 评估层 · 测试 / 模拟卷
> **核心：随机、综合、主次分明；测试只验证"能不能考出"，不追求形式完整。**

- 综合卷 5 科随机组卷，以现代汉语+古代汉语为主
- 不写论述、全出简答；单科卷不升 150 分制
- 多选抽题规则可放宽（测试题贵精也贵多）
- **考试倒计时为象征性展示**（首页「距考试还有 N 天」），无计划倒排，不给用户强加复习节奏

### 2.5 交互层 · UI / 动效
> **核心：流畅克制、背景不穿帮、用户可控。**

- iOS 式横向滑动、动画平滑（背景不浮现其他页面）
- 主题定制开关（审题标记默认关、旗标联动）
- 设置项可删可调（学习目标/每日目标可移除）

### 2.6 工程层 · 打包 / 版本 / 数据
> **核心：每条数据可校验，每个版本可回退。**

- formatVersion 演进、App 自动选最高版本（换 zip 无需改代码）
- 打包脚本自动校验（黑名单 / 字母一致性 / 洗牌同步解析）
- 版本备份保底（v0.13 备份），数据库 onUpgrade 增量迁移

### 2.7 质量层 · 审查闭环
> **核心：P0/P1/P2 分级、交叉验证、宁缺毋滥。**

- 硬错配 → 无实质 → 格式污染 三级分类
- "宁肯不拆"保住简答/论述质量
- 每次打包跑全量扫描 + 覆盖率报告 + 独立复核

## 3. 元理念（贯穿所有环节）

> **结构给足，自由留给用户；数据可校验，行为可回退。**

- **结构给足** = 知识点框架、题型分层、目录先行、判分规则明确
- **自由留给用户** = 背题不打扰、目标可删、倒计时象征性、审题标记默认关
- **数据可校验** = 打包防线、覆盖率、P0/P1/P2 分级、manifest 一致性
- **行为可回退** = 版本管理、备份保底、git、数据库增量迁移

## 4. 验收清单（每个新功能对照）

| # | 检查项 | 违反即打回 |
|---|---|---|
| 1 | 服务于"知识点被记住或被用出"？ | 无关功能不立项 |
| 2 | 不违背"记忆—应用"分层？ | 混层即改 |
| 3 | 数量扩张是否损伤质量？ | 宁缺毋滥 |
| 4 | 是否给用户留了自由度（可关/可删/象征性）？ | 强制则改 |
| 5 | 数据改动是否可校验、可回退？ | 无防线不发布 |
| 6 | 交互是否流畅克制、不穿帮？ | 动画残影即修 |
