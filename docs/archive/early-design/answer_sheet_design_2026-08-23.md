# 答题卡功能设计（修订版 v2）

> 日期：2026-08-23 · 状态：待确认后实施
> 基于 `app/lib/ui/practice_page.dart` 现有结构设计（`_queue` 本轮题列表 + `_index` 当前索引 + `Grade` 四档判分）

## 1. 目标

刷题过程中随时打开"答题卡"：查看本轮已答/未答/对错分布，按题型分区展示，点击题号经确认后跳转到对应题；完成页提供整轮回顾。

## 2. 状态层改造（后端层，最小改动，不碰 SQLite）

### 2.1 新增按题结果表
```dart
// 与 _queue 对齐，length == _queue.length；null = 未答
final List<Grade?> _results = [];   // _load() 完成 queue 赋值后初始化填充 null
```
- `_submit()` 判分后写入 `_results[_index] = grade`（`Grade.skip` 也写入，但不视为已答）。
- **三态口径**（用户确认：无"部分对"）：`correct` → 对；`wrong` **与 `partial`** → 错（红）；`skip`/null → 未答。
  - 注：判分逻辑 `data/grading.dart` 不改（多选部分选中仍产出 partial），仅在答题卡展示时把 partial 归入"错"。
- 完成页 `_SummaryView` 读取同一份 `_results` 做整轮回顾。

### 2.2 跳题 `_jumpTo(int i)`
- 校验 `0 <= i < _queue.length`。
- `setState`：`_index = i`；清空 `_selection`、`_submitted = false`、`_grade = Grade.skip`、`_flagged = false`；重置 `_questionStartedElapsedSeconds`（计时按新题重新起算）。
- 复用现有 `_loadFlagState()` 与 `_saveProgressIfNeeded()`。
- **跳题语义（用户确认）**：跳到别题后，被跳离的题若未判分，保持"未答"（结果不记录）；可随时跳回继续作答。跳题 ≠ 跳过。

### 2.3 本轮已答计数
由 `_results` 派生（`grade != skip && grade != null`），替代/并行现有 `_correct/_partial` 计数，避免两套口径。

## 3. UI 设计

### 3.1 入口
- 刷题页 AppBar 增加"答题卡"图标按钮（做题中随时可开）。
- 完成页（`_SummaryView`）增加"查看答题卡"按钮（整轮回顾，此时结果全量）。

### 3.2 弹层结构（ModalBottomSheet，可滚动，约 70% 屏高）
```
┌─────────────────────────────┐
│ ← 返回（左上角）     答题卡    │  ← 收起按钮在左上角（用户确认）
├─────────────────────────────┤
│ 已答 15 │ 未答 5 │ 对 9 │ 错 6 │  ← 四个概览数字
│ 图例：绿=对 红=错 灰=未答 蓝框=当前 │
├─────────────────────────────┤
│ 单选      12 题 · 对7 错4 未答1 │
│ [1][2][3][4][5][6]           │  ← 每行 6 格
│ [7][8][9][10][11][12]        │
│ 多选      3 题 · 对1 错1 未答1 │
│ [13][14][15]                 │
│ 判断      3 题 · …            │
│ 填空 / 简答（仅本轮出现的题型）│
└─────────────────────────────┘
```

### 3.3 配色（三态，浅底深字，适配深色模式）
| 状态 | 色 |
|---|---|
| 答对 | 绿底（如 #EAF3DE 底 / 深绿字） |
| 答错（含 partial） | 红底（如 #FCEBEB 底 / 深红字） |
| 未答 | 灰白底 + 浅边框 |
| 当前题 | 蓝色加粗边框 + 题号高亮 |

### 3.4 点格子交互（用户确认：需二次确认）
1. 点任意题号格子 → 弹出确认框：**"跳转到第 N 题？"**（正文注明"当前题未作答将保留为未答，可随时跳回"）
2. 确认 → 收起弹层 → `_jumpTo(N)` 定位到该题
3. 取消 → 停留在弹层继续查看

### 3.5 完成页回顾
完成页弹层同布局，但无"当前题"高亮（已结束）；全部格子为对/错（无未答）；支持点击题号跳转查看该题解析（完成页已有查看能力则复用）。

## 4. 边界情况
- 弹层打开期间计时不停（刷题计时与答题卡无关）。
- 跳题后进度写入：`_saveProgressIfNeeded()` 已按 `_index` 保存，跳题后自动续到新位置。
- 空队列/最后一题边界：`_jumpTo` 越界防护；弹层在 `_queue.isEmpty` 时不显示入口。
- 深色模式：格子红/绿/灰改用主题色变量（沿用现有 `_ResultCard`/`typeColor` 的暗色适配方式）。
