二、缺陷详情

P1 · 数据刷新 缺陷 #1：dock tab 切换不触发数据刷新
  • 现象：刷题 3 题后，dock 切回「今日」仍显示旧数据（4504 新题 / 0 错题）；手动 reload 后数据全对（4501 新题 / 2 错题 / 今日 3 题 / 33% 正确率）。统计页同理。
  • 根因：home_page.dart 的 _refresh 仅在 initState 与 _push（Navigator push 返回）时调用；dock 切换是 root_page 内部 tab 切换，不重建 HomePage → 不触发刷新。
  • 同源影响：mock_exam_list_page.dart 的 _load 仅在 initState 执行，从考试页返回列表后「最近 X 分」需 reload 才更新。
  • 数据层：无问题（刷新后完全正确，含今日统计/近7日/题型分布/错题本）。
代码证据
lib/ui/home_page.dart L87 _init / L118 _refresh / L168 _push；lib/ui/mock_exam_list_page.dart L46 _load（仅 initState）。
P1 · 渲染层 缺陷 #2：FlippableCard 高度塌陷 → 知识点卡不可见
  • 现象：背诵页「知识点卡」tab 视觉空白（顶部进度「知识点已掌握 0/10」正常、语义树有节点，但画面无卡片）。稳定复现 3 次。
  • 根因：lib/ui/widgets/flippable_card.dart 的 widget.height 参数未用于布局，内部仅 Stack(fit: StackFit.expand)；在 ListView 无界高度下 Stack 高度塌陷为 0 → 卡片不可见。
  • 影响范围：FlippableCard 仅被 knowledge_memorize_page.dart 使用（M4 知识点卡 tab + M5 知识背诵共享）。
代码证据
lib/ui/widgets/flippable_card.dart（height 声明 L24，未参与布局）；lib/ui/knowledge_memorize_page.dart L264 使用。
P2 · 统计口径 缺陷 #3：模拟考未答题计入今日统计分母
  • 现象：实际作答模拟考 3 题（2 对 1 错），交卷后首页「今日做题量」从 3 变 43、正确率从 33% 跌至 7%，「已答 43/901 题」。
  • 根因：submitMockSession 对全部 40 题写入 answer_logs，未答题（Grade.skip）也落库；todayOverview 把 skip 计入 todayAnswered 与正确率分母。
  • 影响：模拟考会显著稀释「今日做题量 / 今日正确率 / 章节已答数」，与刷题口径不一致（刷题只记已答题）。
代码证据
lib/data/quiz_repository_mock.dart L68-92（逐题写 answer_logs 含 skip）、L280-327 todayOverview（分母含 skip）。
设计确认 · 非缺陷 M4 背诵「背 1 次退出重进不保留」

实测：背会第 1 题后退出重进，已会 0/71 从第 1 题重来；连续背会 2 次（streak→2，达到 mastered）后退出重进，已会 1/71 且从第 2 题开始。

  • 判定：recordMemorize 状态机 streak≥2 → mastered 才归档排除，单次背会为 learning 会重推——「不背单词式」推流设计，跨会话归档逻辑正确。
代码证据
lib/data/quiz_repository_memorize.dart L12 recordMemorize / L53 memorizeStates；lib/ui/memorize_page.dart L42 _pushBackInterval=5。
待确认点 M3 刷题退出无总结页/完成页

实测：答题卡跳题正常（跳转到第 10 题 ✓），但 Back 退出刷题直接回章节概览，未见完成/总结页（如全部答完是否出现总结、完成页答题卡回顾功能未实测）。建议在修改会话中一并核对 practice_page 完成态分支。
