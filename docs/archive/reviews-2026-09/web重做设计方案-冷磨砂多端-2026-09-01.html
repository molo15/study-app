一、现状诊断（差距分析）

基于对原型 ui-v2-cold-frost.html（1500 行，冷磨砂 v2 多端设计参考）的完整读取，以及当前 App 代码现状（主题系统 / 导航 / 响应式 / 组件库）的核对，差距如下：

维度原型 v2（目标）当前 App结论
设计语言三档玻璃（glass/glass-sm/glass-3）+ 光斑沉浸背景 + 白高光 + 彩色柔影冷磨砂已实现：AppCard 玻璃基元 + FrostBackground 全局背景 + 弹窗玻璃化已对齐·微调
主题预设冷磨砂默认 + 备选5 预设（冷磨砂/墨绿/纸米/经典蓝/夜间）已超原型
手机导航底部 5 Tab + 中央背题圆钮GlassTabBar 5 Tab + 中央圆钮浮层（已修 dock 遮挡）+ 上滑隐藏已对齐
平板/桌面导航侧边栏（66px 图标 / 232px 全宽）所有端均为底部 dock，无侧边栏主差距
答题卡形态手机整页 / 平板右下浮层 / 桌面右侧常驻单形态，未多端适配主差距
宽屏布局home/stats/mock 双栏、bank/mem/chaps 双列网格内容限宽（560/760/920）单列为主主差距
页面覆盖5 主页面 + 8 二级页全部页面已有，功能完整功能全

结论：主题与手机端已基本对齐；重做核心在「多端形态」——侧边栏导航、答题卡三形态、宽屏多栏布局。功能与数据零改动。

二、目标

① 令牌对齐
三档玻璃 / 圆角 26/18/13 / 彩色柔影 / 白高光 / 动效节奏（300-500ms 级联）
② 四端导航
手机=底部 5 Tab + 中央圆钮；平板/桌面=侧边栏（图标 / 全宽）
③ 答题卡三形态
手机=整页 push · 平板=右下浮层 · 桌面=右侧常驻面板
④ 宽屏多栏
home/stats/mock 双栏、bank/mem/chaps/me 双列网格、答题卡桌面 6 列
⑤ 零回退
刷题/背诵/模拟考链路不破坏，数据/存档/主题预设保留，测试基线不降

三、过程（分 6 阶段）

P0 · 设计令牌落地统一三档玻璃基元
  • 扩展 widgets/app_card.dart：AppCard 增加 level（primary/secondary/tertiary），对应 glass / glass-sm / glass-3 三档透明度与 blur（24/16/12px）
  • 圆角 / 阴影 / 高光令牌统一为常量，与原型 26/18/13 对齐
  • 改动：1 个基元文件 + 引用处低风险替换
P1 · 导航重构（核心）侧边栏 + dock 共存
  • 新增 widgets/app_sidebar.dart：三态侧边栏（66px 图标 / 可展开 200px / 全宽 232px），导航项 今日/题库/背题/统计/我的，含考试倒计时脚注
  • root_page.dart 按 responsive.dart 断点切换：compact→底部 GlassTabBar；medium/expanded→侧边栏 + 隐藏 dock
  • 侧边栏展开动画 + 选中态玻璃高亮（对齐原型 .s-item.on）
  • 改动：新增 1 组件 + root_page / responsive 调整
P2 · 答题卡三形态整页 / 浮层 / 常驻
  • 抽象答题卡视图 practice_answer_sheet.dart：手机=Navigator 整页；平板=右下角浮层（width 300 / max-height 74% / 圆角）；桌面=右侧常驻面板（width 280 / 全高 / 滑入）
  • 对齐原型 legend（当前/已答/答错/未答/存疑/审题标记）+ 题号网格（桌面 6 列）+ 题号跳转
  • 改动：practice_answer_sheet + 调用处（练习/模拟考共享）
P3 · 宽屏多栏布局双栏 / 多列网格
  • home / stats / mock：isWideScreen 时切换双栏 grid（对齐原型 .d-desktop 双栏）
  • bank 列表 / 背题列表 / 章节列表 / 我的设置项：双列网格
  • 答题内容限宽居中（760px）保持可读性（原型 .d-desktop 已如此）
  • 改动：home/stats/mock_exam_list/bank/memorize/chapter 布局分支
P4 · 页面细节对齐视觉与交互微调
  • 首页「今日学习流」hero + 环形进度 + 今日队列卡；背题总览科目列表 + 掌握度环；章节概览知识点折叠
  • 错题本筛选 chips（全部/各科）+ 错 N 次标签；模拟考历史列表 + 结果页成绩环 + 各科得分条 + 逐题复盘
  • 审题标记（练习）/ 存疑标记（模拟考）、答题卡题号跳转、进度 seg 条、级联浮现动画（StaggeredItem）
  • 改动：仅对已有页面做布局/视觉微调，不动数据层
P5 · 验证与回归三层验证
  • 代码层：`flutter analyze` 0 warning
  • 测试层：全量 `flutter test`（当前 88 项基线）全绿 + 新增侧边栏/答题卡形态/宽屏 widget 测试
  • 实操层：浏览器 4 端宽度逐一跑（手机 392 / iPad 768 / 平板 920 / 桌面 1180），对照原型逐项比对

五、封装

维度方案
Web（PWA）保持不动：manifest / 自定义 sw.js / 离线缓存 / sqlite3.wasm / canvaskit 本地化 全部沿用。重做只改 UI 层，不触碰封装脚本（post_build_sw.py 仍自动写入新 BUILD_ID）
多端（浏览器）本次重做的「多端」= 同一 web 产物在不同窗口宽度下自适应（手机/平板/桌面浏览器），无需额外封装
Androidandroid/ 目录保留，Flutter 代码重构后同步生效（UI 层共用），不在本次构建验证范围
桌面安装包不在本次范围（release/ 当前为空）。如需 Windows exe，需另立 Electron/Tauri 或 Flutter Windows 打包流程，建议作为后续独立任务
