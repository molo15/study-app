## 2. 问题清单

### P1 · 重要缺陷

#### P1-1 · sw.js 源文件与构建产物不一致，下次构建将回退改进

- **证据**：
  - 源文件 `app/web/sw.js:11`：`const RUNTIME_CACHE = 'quiz-runtime-' + BUILD_ID;`（带 BUILD_ID）
  - 构建产物 `build/web/sw.js:14`：`const RUNTIME_CACHE = 'quiz-runtime';`（不带 BUILD_ID，且有注释"运行时缓存不带 BUILD_ID：题库 zip 等资源 URL 自带版本号，跨构建版本保留运行时缓存可避免每次发版后全量重新下载题库"）
- **影响**：构建产物中的改进（运行时缓存不带 BUILD_ID，避免每次发版清空题库缓存）未同步回源文件。下次运行 `flutter build web` 时，源文件（旧版）会覆盖构建产物，`post_build_sw.py` 只替换 `__BUILD_ID__` 不修改其他内容，导致 RUNTIME_CACHE 回退为带 BUILD_ID 版本。每次发版后用户的题库缓存（1.2MB）被清空，需重新下载。
- **修复建议**：将构建产物 `build/web/sw.js` 中的改进（RUNTIME_CACHE 不带 BUILD_ID + 注释）同步回源文件 `app/web/sw.js`。

#### P1-2 · sw.js 预缓存路径错误：`AssetManifest.json` 不存在

- **证据**：
  - `build/web/sw.js:35`：`'./assets/AssetManifest.json'` 在预缓存清单中
  - 构建产物中实际存在：`assets/AssetManifest.bin`（二进制，Flutter 运行时实际使用）和 `assets/AssetManifest.bin.json`（调试用 JSON 表示）
  - **`assets/AssetManifest.json` 不存在**（Flutter 新版已弃用旧版 JSON 清单格式）
- **影响**：SW install 阶段预缓存 `AssetManifest.json` 时返回 404，`Promise.allSettled` + `if (res.ok)` 静默跳过，不影响 SW 安装。但 AssetManifest 未被预缓存，离线首开时需要从网络获取 `AssetManifest.bin`（虽然运行时缓存优先策略会在首次访问后缓存，但首次离线打开可能失败）。
- **修复建议**：将 sw.js 预缓存清单中的 `./assets/AssetManifest.json` 改为 `./assets/AssetManifest.bin`。

### P2 · 改进建议

#### P2-1 · canvaskit .symbols 调试符号 8.18MB 存在于生产构建产物

- **证据**：`build/web/canvaskit/` 下 6 个 `.symbols` 文件，总计 8.18 MB：
  - canvaskit.js.symbols (1.3MB)
  - chromium/canvaskit.js.symbols (1.2MB)
  - webparagraph/canvaskit.js.symbols (0.9MB)
  - skwasm.js.symbols (1.5MB)
  - skwasm_heavy.js.symbols (1.6MB)
  - wimp.js.symbols (1.7MB)
- **影响**：.symbols 文件是调试符号，生产环境不需要。用户浏览器不会请求这些文件（Flutter 运行时只加载 .js + .wasm），但它们占用部署空间和部署时间。
- **修复建议**：构建后清理脚本删除 `build/web/canvaskit/**/*.symbols`，或在部署时排除。可减少 8.18MB 部署体积。

#### P2-2 · Web 构建产物中 NotoSansSC-subset.ttf (7.1MB) 是死资源

- **证据**：
  - `main.dart:30-32`：Web 端通过 FontLoader 加载 `assets/fonts/NotoSansSC-subset.woff2`（2.9MB），io 端加载 `.ttf`（7.1MB）
  - 构建产物中同时存在 `.ttf` (7.1MB) 和 `.woff2` (2.9MB)
  - Web 端代码只引用 `.woff2`，`.ttf` 不会被 Web 端加载
- **影响**：由于 Flutter 不支持按平台条件包含 assets（`pubspec.yaml` 的 `assets:` 段对所有平台生效），`.ttf` 被打包进 Web 构建产物。Web 端这 7.1MB 是死资源，占用部署空间。
- **修复建议**：构建后清理脚本删除 `build/web/assets/assets/fonts/NotoSansSC-subset.ttf`。注意：sw.js 预缓存清单中只有 `.woff2`，没有 `.ttf`，所以删除 ttf 不影响 SW 预缓存。

#### P2-3 · 无 gzip/brotli 压缩版本，依赖服务器配置

- **证据**：构建产物中只有原始文件，无 `.gz` 或 `.br` 预压缩版本。大文件包括：
  - main.dart.js：3.3 MB（gzip 后约 1.1 MB，减少 67%）
  - canvaskit .wasm 总计：27.5 MB（gzip 后约 12-15 MB，减少 45-55%）
  - NotoSansSC-subset.woff2：2.9 MB（已压缩，gzip 收益小）
  - sqlite3.wasm：0.7 MB（gzip 后约 0.3 MB）
- **影响**：如果部署服务器未配置 gzip/brotli 压缩，用户首次加载需下载 ~52MB（实际请求约 35MB，因为 canvaskit 只加载一个变体）。弱网环境首屏加载慢。
- **修复建议**：① 部署时确保服务器（Nginx / Vercel / GitHub Pages 等）启用 gzip 和 brotli 压缩；② 或构建后用脚本预生成 `.gz`/`.br` 文件，服务器配置直接服务预压缩文件。

#### P2-4 · 题库版本不一致：三科 v0.14.1，两科 v0.14.0

- **证据**：`build/web/assets/assets/banks/` 下 5 个题库 zip：
  - bank-gudai-hanyu-v0.14.1.zip（古代汉语）
  - bank-xiandai-hanyu-v0.14.1.zip（现代汉语）
  - bank-zhongguo-xiandai-wenxue-v0.14.1.zip（现代文学）
  - bank-zhongguo-dangdai-wenxue-v0.14.0.zip（当代文学）
  - bank-zhongguo-gudai-wenxue-v0.14.0.zip（古代文学）
- **影响**：可能是正常的分批更新（不同科目更新频率不同），但需确认是否为有意状态。若当文和古文有未合并的更新，可能导致用户看到的题目版本不一致。
- **修复建议**：确认当文和古文是否有 v0.14.1 待发布；若为有意分批更新则无需处理，建议在题库管理文档中记录各科目版本。

## 3. 亮点（值得保留的构建配置）

1. **canvaskit 本地化**：`flutter_bootstrap.js` 中 `canvasKitBaseUrl: "canvaskit"`，canvaskit 从本地 `web/canvaskit/` 加载，免 Google gstatic CDN，国内更快更稳。

2. **字体加载优化**：不放入 `pubspec.yaml` 的 `fonts:` 段（避免 Flutter 预下载 FontManifest 声明的全部字体，旧版 NotoSansSC-VF.ttf 17.7MB 首屏必下载），改用 `FontLoader` 运行时按需加载子集字体——Web 端 woff2 (2.9MB)，io 端 ttf (7.1MB)。Web 端 `await` 加载与 canvaskit/main.dart.js 并行下载，不增加总启动时间，且首帧字体已就绪，避免 fallback 到 Google Fonts CDN（被墙时中文不渲染）。

3. **PWA Service Worker 策略合理**：
   - App Shell 预缓存（20 个核心资源，含 sqlite3.wasm + sqflite_sw.js 数据库引擎）
   - 静态资源缓存优先（Cache First）
   - 页面导航网络优先（Network First）+ 离线兜底
   - 仅处理同源 GET，跨域走网络
   - 预缓存失败不阻塞 SW 安装（`Promise.allSettled` + `skipWaiting`）

4. **版本化缓存机制**：BUILD_ID = `main.dart.js` 的 SHA-256 前 12 位，由 `tools/post_build_sw.py` 构建后注入。缓存命名空间 `quiz-shell-{BUILD_ID}`，发布新版本后 SW 内容变化 → 浏览器检测更新 → activate 清理旧缓存。

5. **运行时缓存不带 BUILD_ID**（构建产物版）：`quiz-runtime` 缓存名固定，题库 zip 等 URL 自带版本号（如 v0.14.1），跨构建版本保留运行时缓存，避免每次发版后全量重新下载题库（1.2MB）。

6. **数据库引擎预缓存**：sw.js 预缓存清单包含 `sqlite3.wasm` (0.7MB) 和 `sqflite_sw.js` (0.26MB)，确保离线时 Web 端数据库可用。

## 4. 建议的构建后清理脚本

建议创建 `app/tools/post_build_cleanup.py`，在 `flutter build web --release` + `post_build_sw.py` 之后运行：

```python
#!/usr/bin/env python3
"""构建后清理：删除 Web 构建产物中的死资源和调试文件。
- canvaskit *.symbols（调试符号，生产不需要）
- NotoSansSC-subset.ttf（Web 端只用 woff2，ttf 仅 io 端用）
- flutter_service_worker.js（Flutter 空壳，未被注册）
"""
import os, shutil

BUILD = os.path.join(os.path.dirname(os.path.dirname(os.path.abspath(__file__))), 'build', 'web')

def remove(path):
    p = os.path.join(BUILD, path)
    if os.path.exists(p):
        if os.path.isdir(p): shutil.rmtree(p)
        else: os.remove(p)
        print(f'  已删除: {path}')

# canvaskit .symbols
for root, dirs, files in os.walk(os.path.join(BUILD, 'canvaskit')):
    for f in files:
        if f.endswith('.symbols'):
            remove(os.path.relpath(os.path.join(root, f), BUILD))

# Web 端死资源 ttf
remove('assets/assets/fonts/NotoSansSC-subset.ttf')

# Flutter 空壳 SW
remove('flutter_service_worker.js')

print('清理完成')
```

配合 `build_web.bat`：
```bat
@echo off
flutter build web --release
python tools/post_build_sw.py
python tools/post_build_cleanup.py
```
