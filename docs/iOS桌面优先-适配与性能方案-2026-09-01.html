③ 方案 gzip / brotli 部署（iOS 蜂窝最大杠杆）

实测 gzip 收益（本机 python gzip level 9）：

资源原始gzip 后节省

nginx 配置（生产部署，brotli 优先 + gzip 回退）：

# /etc/nginx/conf.d/study_app.conf（片段）
server {
    listen 443 ssl http2;
    server_name 你的域名;
    root /srv/study_app/web;   # build/web 部署目录
    index index.html;

    # brotli（需 ngx_brotli 模块；无则只开 gzip 即可）
    brotli on;
    brotli_comp_level 6;
    brotli_static on;                 # 预生成 .br 文件则直接发
    brotli_types application/wasm application/javascript application/json
               text/css text/plain font/woff2 image/svg+xml;

    # gzip 回退（兜底）
    gzip on;
    gzip_comp_level 6;
    gzip_vary on;
    gzip_types application/wasm application/javascript application/json
               text/css text/plain image/svg+xml;

    # wasm 正确 MIME + 强缓存（构建指纹已含在 sw.js，资源本身可长缓存）
    location ~* \.(wasm|js|woff2|png|svg)$ {
        add_header Cache-Control "public, max-age=31536000, immutable";
        add_header X-Content-Type-Options nosniff;
    }

    location = /index.html { add_header Cache-Control "no-cache"; }
    location = /sw.js     { add_header Cache-Control "no-cache"; }
}
预期：冷加载网络 13.2MB → 约 6.5–7MB；iOS 蜂窝场景（4G/5G）首屏下载时间近乎减半；桌面亦同步受益。注意：本地方便起见可用 python -m http.server 开发，正式部署必须上压缩。
