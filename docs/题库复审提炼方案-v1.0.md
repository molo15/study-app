> 2026-08-27 · 背景：R1 恢复旧基础题后 5 库合计 6380 题（旧基础 4025 + 新基础 1146 + 新测试 1209），
> 题量过大、变式重复多，需复审提炼。本方案先定设计与题量框架，确认后执行。

## 2. 治理设计：四层题池分离

用户明确要求"背题、知识点、这些都分开"，按此重构图库结构：

```
① 知识点框架层（overview）  每章知识概览/思维导图 —— 不答题，只导航
② 背题层（背诵卡）          知识点记忆卡（要点+答案）—— 不背单词式推送，独立于复习队列
③ 基础题层                  知识点直问直答（选择/填空/判断）—— 贵多不贵精，但不重复
④ 测试题层                  综合/应用 —— 贵精，覆盖考点不重复
```

- ②背题卡**不重复建**：由提炼后的代表性基础题**自动派生**（题干→记忆点、答案→卡内容），一知识点一卡
- ③基础题目标：**每知识点 2-3 道**，只考"知识点的记忆"，不考综合
- ④测试题目标：**每章考点全覆盖**，同一考点最多 1 题

## 3. 复审流水线（R2-R5）

```
R2 选项洗牌     全部选择题洗牌 + answer 文本重算（修复"连着选 A"，不改内容）
R3a 完全去重    同题干归一化去重（实测 67 题，直接清）
R3b 变式提炼    按「章节 + tags 核心知识点」聚合 → 识别"同考点换问法" → 每知识点择优保留 2-3 题
R3c 质量审查    解析缺口补全 + rewrite 名单定向修（答案/解析错的真坏题）
R4 扩充         现代汉语 ← 试题库（现成）；古代汉语 ← 经典笔记审查现有题；其他科纯提炼
R5 打包         覆盖率报告 + verify → v0.12.0
```

### 变式重复判定规则
- **聚合键**：chapter + tags 核心词（去"文学史题库"等通用标签）
- **变式特征**（命中任一即判）：同考点答案落点相同；stem 归一化后仅换问法/语序；选择题↔填空互转
- **保留规则**：优先保留新题（格式已标准化）+ 解析完整 + 干扰项有效者；其余标记 `dedup_variant` 归档不删（留可追溯）

| 题库 | 当前 | 提炼后建议 | 说明 |
|---|---|---|---|
| 现文史 | 1934 | **~1000-1100** | 27 章，重点压基础题（1536→~700） |
| 现代汉语 | 1330 | **~900（扩充后 ~1100）** | 7 章，扩充后再微调 |
| 古代汉语 | 1125 | **~750** | 13 章 |

| 古文史 | 854 | **~600** | 9 章 |

> 目标：基础 ~2800 / 测试 ~1300，覆盖 68 章全部知识点，但同知识点不同问法的题不超过 2-3 道。
