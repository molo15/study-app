## 2. 设计目标

### 2.1 发布目标

- 产出一个 **唯一可辨识的正式版 APK**：`考研刷题-v0.8.0-release.apk`；
- 可通过微信/QQ/网盘发给同学直接安装（无需开发者选项）；
- 应用在手机桌面显示中文名「考研刷题」和专属图标；
- 启动时显示品牌过渡（不再白屏），2~3 秒后进入首页；
- Release 签名密钥安全保存，后续版本可续用同一签名升级。

### 2.2 不改的内容

- 应用内所有业务逻辑（刷题、判题、间隔重复、统计、模拟卷）；
- 题库包内容（v0.8.0，3718 题 + 5 张模拟卷）；
- 主题系统、设置、计时器、续刷等全部 UI 功能；
- 数据库表结构；
- 包名 `dev.kaoyan.quiz_app`（改名需要重签+迁移，风险高，不推荐）。

## 3. 实施方案

### 3.1 应用名称

修改 `android/app/src/main/AndroidManifest.xml`：

```xml
android:label="考研刷题"
```

Flutter 已用 `MaterialApp(title: '考研刷题')` 设置标题栏，此次只改 Android 原生 launcher 显示名——两个互相独立，不影响 App 内标题。

### 3.2 应用图标

#### 3.2.1 设计方向

考研刷题 App 的图标应传达：**学术、专注、典籍感**。建议：

- 主视觉：一本打开的书 + 一支笔（或放大镜/星标），简洁线条风格；
- 底色：深青色（`#00696D`，与 App 默认主色一致）；
- 圆角方形图标（Android 自适应图标规范）；
- 避免文字（小尺寸下不可读）。

#### 3.2.2 技术方案

Android 自适应图标需两个图层：

- **前景层**（`ic_launcher_foreground.xml`）：矢量书+笔图案，居中安全区（距边缘 18% 内）；
- **背景层**（`ic_launcher_background.xml`）：纯色 `#00696D`。

同时生成 5 个密度的传统 `ic_launcher.png`（兼容旧版 Android 启动器），放置于 `mipmap-mdpi/hdpi/xhdpi/xxhdpi/xxxhdpi`。

**实现方式**：用 Python 脚本 + Pillow 库生成 PNG（48×48 → 192×192 五档），各密度下前景图案保持清晰。脚本输出到 `android/app/src/main/res/mipmap-*/` 覆盖默认图标。

#### 3.2.3 自适应图标配置

在 `res/mipmap-anydpi-v26/` 下创建 `ic_launcher.xml`：

```xml
<adaptive-icon xmlns:android="http://schemas.android.com/apk/res/android">
    <background android:drawable="@drawable/ic_launcher_background"/>
    <foreground android:drawable="@drawable/ic_launcher_foreground"/>
</adaptive-icon>
```

### 3.3 启动页

#### 3.3.1 设计方向

App 冷启动时不再白屏，改用品牌过渡：

- 背景色：与 App 主题背景一致（浅色 `#F4F7F6`，深色 `#101418`）；
- 居中显示：App 图标（128×128dp，与桌面图标一致）+ 下方「考研刷题」文字；
- 无动画（保持轻量，快速进入首页）；
- 浅色和深色模式各自一套 `drawable`（`values/styles.xml` 与 `values-night/styles.xml`）。

#### 3.3.2 技术方案

修改 `launch_background.xml`（浅色）和新增 `drawable-night/launch_background.xml`（深色），使用 `layer-list` + `bitmap` 居中布局：

```xml
<layer-list>
    <item android:drawable="@color/launch_bg" />
    <item>
        <bitmap android:gravity="center" android:src="@drawable/launch_logo" />
    </item>
</layer-list>
```

- `launch_logo.png`：128×128dp 的图标 + 文字组合（用 Pillow 生成）；
- 颜色：`launch_bg` 浅色 `#F4F7F6`，深色 `#101418`；
- 启动页在 Flutter 引擎初始化完成后自动消失（`styles.xml` 中 `flutterAutoRemoveLaunchScreen` 已默认启用）。

### 3.4 Release 签名

#### 3.4.1 密钥生成

在项目根目录生成密钥库（不提交到 Git）：

```bash
keytool -genkey -v -keystore android/kaoyan-release.keystore \
  -alias kaoyan -keyalg RSA -keysize 2048 -validity 10000 \
  -storepass <密码> -keypass <密码> \
  -dname "CN=考研刷题, OU=Kaoyan, O=Kaoyan, L=Beijing, ST=Beijing, C=CN"
```

- `validity 10000` ≈ 27 年，保证长期续签；
- 密钥库文件 `android/kaoyan-release.keystore` 添加到 `.gitignore`；
- 密码和别名记录在安全位置（不在本文档中明文存储）。

#### 3.4.2 Gradle 配置

在 `android/app/build.gradle.kts` 中增加 `signingConfigs`：

```kotlin
signingConfigs {
    create("release") {
        storeFile = file("kaoyan-release.keystore")
        storePassword = System.getenv("KEYSTORE_PASSWORD") ?: "fallback"
        keyAlias = System.getenv("KEY_ALIAS") ?: "kaoyan"
        keyPassword = System.getenv("KEY_PASSWORD") ?: "fallback"
    }
}
buildTypes {
    release {
        signingConfig = signingConfigs.getByName("release")
        // 开启混淆和资源压缩（可选，减小 APK 体积）
        isMinifyEnabled = true
        isShrinkResources = true
        proguardFiles(getDefaultProguardFile("proguard-android.txt"), "proguard-rules.pro")
    }
}
```

密码通过环境变量传入（CI 友好），本地开发时用 `key.properties` 文件（不提交 Git）或直接硬编码密码（仅单人开发场景）。

#### 3.4.3 构建命令

```bash
flutter build apk --release
# 输出：build/app/outputs/flutter-apk/app-release.apk
```

### 3.5 版本号管理

在 `android/app/build.gradle.kts` 的 `defaultConfig` 中显式声明：

```kotlin
versionCode = 1
versionName = "0.8.0"
```

- `versionCode`：整数，每次发布 +1（Google Play / 安装器用于判断升级）；
- `versionName`：语义化版本，与题库包版本对齐（当前 v0.8.0）。

### 3.6 权限声明

当前 `AndroidManifest.xml` 无多余权限。备份导出需要 `WRITE_EXTERNAL_STORAGE`（Android 10 以下）或 `MANAGE_EXTERNAL_STORAGE`（Android 11+），但当前备份功能使用 `getApplicationDocumentsDirectory`（应用私有目录），无需额外权限。

**本次不新增权限声明**——保持零权限，安装时不会弹出任何权限请求。

### 3.8 工具脚本

写一个 Python 脚本 `tools/release/gen_assets.py`：

- 用 Pillow 生成 5 个密度的 `ic_launcher.png`（48/72/96/144/192）；
- 生成 `launch_logo.png`（128×128dp 适配，实际 384×384px）；
- 生成 `ic_launcher_foreground.xml` 和 `ic_launcher_background.xml`；
- 输出到对应 `android/app/src/main/res/` 路径。

## 4. 实施步骤

### 第一阶段：生成视觉资产（脚本化，约 10 分钟）

1. 写 `tools/release/gen_assets.py`；
2. 运行生成全部图标和启动页资源；
3. 手动检查 5 个密度的图标清晰度，在模拟器桌面验证。

### 第二阶段：配置签名与版本（手工 + 脚本，约 15 分钟）

1. 用 `keytool` 生成密钥库；
2. 修改 `build.gradle.kts`（签名配置 + 版本号 + 混淆）；
3. 修改 `AndroidManifest.xml`（应用名称）；
4. 修改 `.gitignore`（排除密钥文件）。

### 第三阶段：构建与验证（自动化，约 10 分钟）

1. `flutter clean` → `flutter build apk --release`；
2. 检查 APK 签名（`jarsigner -verify`）；
3. 安装到模拟器验证：桌面图标、应用名称、启动页、App 内功能不变；
4. 安装到真机验证（可选，需你提供真机）。

### 第四阶段：APK 分发（手工，由你执行）

1. APK 位于 `build/app/outputs/flutter-apk/app-release.apk`；
2. 重命名为 `考研刷题-v0.8.0.apk`；
3. 通过微信/QQ/网盘发给同学。

## 8. 风险与注意事项

1. **密钥库丢失**：一旦丢失，无法续签同一应用（用户无法覆盖安装升级）。建议备份到安全位置（如加密云盘）；
2. **包名不变**：`dev.kaoyan.quiz_app` 保持不变。改包名需要重签 + 旧用户数据迁移，风险高于收益；
3. **混淆**：首次开启 ProGuard 可能导致 Flutter 插件反射失败。如遇问题，先关闭 `isMinifyEnabled`，后续单独排查；
4. **自适应图标**：Android 8.0+ 显示自适应图标，旧版回退到 mipmap 传统图标。两套都要生成。
